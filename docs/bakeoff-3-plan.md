# Bakeoff 3 – Development Plan

## Technology Stack

- **React:** Frontend application and UI components.
- **Vite:** Development server and build tool.
- **Supabase:** Backend services, authentication, and database access.
- **PostgreSQL:** Relational database for storing application data.
- **JavaScript:** Primary programming language.
- **GitHub:** Version control and project management.

## MVP Features

1. User login and authentication.
2. Loan officer dashboard.
3. Create and submit loan applications.
4. Store loan applications in Supabase.
5. Credit manager dashboard.
6. Review applications and update decisions.
7. Display application statuses.

## Planned Pages

- Login
- Loan Officer Dashboard
- Create Application
- Credit Manager Dashboard
- Application Details / Credit Review

## Development Schedule

### Monday – Setup
- Initialize React using Vite.
- Install dependencies.
- Create Supabase project.
- Connect React to Supabase.
- Document project architecture and development plan.

### Tuesday – Foundation
- Establish React component structure.
- Design the application layout and navigation.
- Configure Supabase database tables.
- Set up authentication.

### Wednesday – Create Application
- Manually build the loan application form.
- Implement form state and validation.
- Connect the form to Supabase.
- Test saving applications to the database.

### Thursday – Dashboards and Reviews
- Build the Loan Officer Dashboard.
- Build the Credit Manager Dashboard.
- Display submitted applications.
- Implement application review and status updates.

### Friday – Testing and Completion
- Test the complete application workflow.
- Fix bugs and improve the UI.
- Verify database functionality.
- Complete project documentation and final evaluation.

## Project Goal

Build a functional loan origination prototype using React and Supabase. Focus on the core workflow of creating, submitting, reviewing, and updating loan applications while keeping the implementation simple and manageable.
